Ahora necesitas completar la instalación siguiendo estos pasos.

⚠️ Antes de continuar, verifica:

1

Abre XAMPP Control Panel

Si no lo tienes abierto, búscalo en el menú de inicio de Windows. Debe estar en: C:\xampp\xampp-control.exe

2

Inicia Apache y MySQL

En el panel de XAMPP, haz clic en "Start" junto a Apache y MySQL. Espera a que ambos estén en verde.

3

Ejecuta el instalador

Una vez que Apache y MySQL estén activos, haz clic en el botón de abajo para ejecutar el script de instalación automática.

⚠️ Importante: Si ves un error de conexión, asegúrate de que MySQL esté ejecutándose en XAMPP.
🚀 Ejecutar Instalación

💡 ¿Qué hará el instalador?

  • Crear la base de datos automáticamente
  • Crear todas las tablas necesarias
  • Configurar los directorios de uploads
  • Generar el archivo de configuración (.env)
  • Preparar todo para que empieces a usar la aplicación
